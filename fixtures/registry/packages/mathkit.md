# mathkit

Small math helpers for fire: a class in fire and a C++ native (`hypot`) for the native backend.

```fire
#import "mathkit"
print(MathKit.Hypot(3, 4))   // 5
```

| Function | What it does |
| --- | --- |
| `Hypot(a, b)` | the length of the hypotenuse |
