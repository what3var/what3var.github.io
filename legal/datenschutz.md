## Kurz

Diese Website und das Paketverzeichnis sind statische Seiten. Wir setzen **keine Cookies**, nutzen
**kein Tracking und keine Analyse**, laden keine Schriften oder Skripte von Dritten und haben keine
Formulare. Wir selbst erheben und speichern keine personenbezogenen Daten.

## Hosting durch GitHub

Die Seiten werden von GitHub Pages ausgeliefert (GitHub, Inc., 88 Colin P. Kelly Jr. Street,
San Francisco, CA 94107, USA). Beim Abruf einer Seite oder einer Paketdatei – auch durch den
Paketmanager `ember` – verarbeitet GitHub technisch notwendige Daten, insbesondere Ihre IP-Adresse,
Datum und Uhrzeit, die abgerufene Adresse und Angaben zu Browser bzw. Programm. GitHub speichert
nach eigenen Angaben die IP-Adressen der Besucher zu Sicherheitszwecken. Rechtsgrundlage ist unser
berechtigtes Interesse an einer sicheren und erreichbaren Website (Art. 6 Abs. 1 lit. f DSGVO).
Dabei können Daten in die USA übermittelt werden; GitHub ist [Stand prüfen: nach dem EU-US Data
Privacy Framework zertifiziert]. Einzelheiten: GitHub Privacy Statement
(https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

Liegen Pakete als Release-Dateien auf GitHub (`github.com/.../releases`), gilt beim Herunterladen
dasselbe.

## Lokale Speicherung im Browser

Wenn Sie das Farbschema (hell/dunkel) umschalten, speichert Ihr Browser diese Wahl lokal
(`localStorage`). Sie wird nicht an uns übertragen und lässt sich in den Browser-Einstellungen
löschen (§ 25 Abs. 2 Nr. 2 TDDDG).

## Inhalte Dritter

Beschreibungen (Readmes) von Paketen stammen von deren Autoren. Enthalten sie Bilder von anderen
Servern, lädt Ihr Browser diese von dort; dabei erhält der jeweilige Anbieter Ihre IP-Adresse.
[Alternative, wenn externe Bilder abgeschaltet werden: Absatz streichen.]
Links auf andere Seiten (z. B. die Quelltexte der Pakete) führen zu Angeboten, für die deren
Betreiber verantwortlich sind.
